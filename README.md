## About Me

- I focus on clean architecture, fast UI, and products that feel good in real use, not just on screenshots.
- I build across the stack with React, Next.js, Node.js, Express, PostgreSQL, MongoDB, and TypeScript.
- I also enjoy lower-level and exploratory work with C++, Java, Python, Arduino, and Solidity.
- I care about maintainability, performance, and presentation, so design and engineering move together.

## Current Focus

- Shipping portfolio-quality full-stack builds with strong UX and sharp visual polish.
- Improving developer workflows with automation, reusable assets, and GitHub Actions.
- Exploring systems-minded problem solving alongside modern web product development.
